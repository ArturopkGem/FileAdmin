# 📁 Administración de Archivos

## Ingeniería en Sistemas Computacionales - 5to Semestre

### 📋 Descripción

Este repositorio contiene los materiales, ejercicios y proyectos desarrollados durante la unidad de aprendizaje **Administración de Archivos**. El curso está diseñado para desarrollar técnicas optimizadas para el manejo de archivos, utilizando Java como lenguaje de programación principal, con el objetivo de diseñar utilerías que incluyan almacenamiento persistente de información.

### 🎯 Competencia de la Unidad

Desarrollar las diversas técnicas de Administración de archivos para el diseño de variadas utilerías que incluyan almacenamiento de información para el desarrollo de su aprendizaje, mediante la teoría y metodología de la disciplina.
